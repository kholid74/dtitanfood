## Food-platform marks

The “Available On” section currently uses temporary, monochrome parent-brand marks from [Simple Icons](https://simpleicons.org/) (CC0 1.0):

- `gojek.svg` — Gojek mark, used as a stand-in for GoFood
- `shopee.svg` — Shopee mark, used as a stand-in for ShopeeFood
- `grab.svg` — Grab mark, used as a stand-in for GrabFood

No official GoFood, ShopeeFood, or GrabFood brand assets were supplied with the brief. These files are placeholders only and should be replaced with the official assets from each platform’s merchant/brand portal before launch. All three platform URLs remain unconfigured, and the UI does not claim an active integration.
